# Security and privacy

This repository is intended for public defensive engineering work.

- Never submit real organizational logs or screenshots.
- Never submit API keys, passwords, cookies, tokens, credentials, or private
  URLs.
- Use RFC 5737 documentation addresses and synthetic identities in examples.
- Anonymize every image before publication.
- Review the full Git history before pushing a public repository.
- If an accidental exposure is found, remove access where possible, preserve
  evidence privately, and contact the maintainer through a private channel.

The searches use example index and sourcetype names that must be adapted to a
target environment. They are not evidence of the infrastructure of any
organization.
