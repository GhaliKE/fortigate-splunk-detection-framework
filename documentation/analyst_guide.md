# Analyst guide

1. Open the global monitoring dashboard.
2. Review current activity and unusual traffic patterns.
3. Open the sensitive access dashboard.
4. Review sources matching the balanced profile.
5. Inspect score components and destination context.
6. Open the SSH dashboard when SSH activity requires deeper analysis.
7. Use drilldowns to review original events.
8. Verify whether the source belongs to an authorized asset.
9. Escalate only after contextual validation.
10. Never treat the score alone as proof of malicious activity.
