# Contributing

Contributions must preserve the public, synthetic nature of this repository.

- Never submit organizational data, internal infrastructure details, or
  unredacted screenshots.
- Use only synthetic examples, preferably RFC 5737 documentation addresses.
- Document every change and preserve the intended read-only Shadow Mode.
- Validate SPL syntax and compatibility with the documented fields.
- Add an explanation and limitations for every new detection or score change.
- Do not claim accuracy, precision, recall, or detection performance without
  labeled validation data.
